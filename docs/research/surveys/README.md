# Method surveys

Pre-implementation notes on how a compression method was scoped and chosen.
Only the surveys that other documents cite are kept here:

- `NEW_METHOD_SURVEY_V21.md`: NestedKV, including the stated venue exception.
- `NEW_METHOD_SURVEY_V22.md`: AnchorKV, including the stated venue exception.
- `NEW_METHOD_SURVEY_V23.md`: RocketKV.

They are working notes, not documentation of shipped behavior. Each method's
page on [veloxquant.dev](https://veloxquant.dev/docs/algorithms/overview)
states what is actually implemented and its limits.
