Method

Recommender + compression estimates are transparent heuristics (a direct port of veloxquant_mlx/tools/mac_recommender.py) — they state when resident RAM savings are unlikely. Token counts and the book comparison are linear KV extrapolations, labelled as approximations. Benchmark charts read measured values committed under figures/. For live numbers on your own machine, run python -m veloxquant_mlx benchmark.
